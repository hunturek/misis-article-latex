# Шаблон научной статьи НИТУ «МИСиС» (LaTeX)

Репозиторий: [sadekovlar/misis-article-latex](https://github.com/sadekovlar/misis-article-latex)

Шаблон воспроизводит оформление из эталонной статьи (`Article_1.docx`).  
**Все параметры оформления заданы в `misisarticle.cls`** — в `.tex`-файле вы только подставляете текст и вызываете команды.

## Оформление

| Элемент | Параметры |
|---------|-----------|
| Формат | A4, **две колонки** (IEEE-style) |
| Поля | верх 1,9 см; низ 2,54 см; лево/право 1,57 см; зазор колонок 0,635 см |
| Шрифт | Times New Roman, **10 pt** (в двухколоночном режиме) |
| Переносы слов | **отключены** по всему документу |
| Абзацный отступ | 0,51 см |
| Классификация | `ГРНТИ …`, `ASJC …`, `OECD …` — подпись и коды **в одной строке** |
| Название | 24 pt, по центру, на всю ширину; после него — строка отступа |
| Авторы | 11 pt; невидимая таблица: **1-й слева, 2-й справа**, между колонками пустой зазор; внутри каждой ячейки текст **по центру** |
| Аннотация | **Аннотация —** текст (метка и текст **жирным**, в колонках) |
| Ключевые слова | **Ключевые слова —** текст (жирным) |
| Раздел | **I. ВВЕДЕНИЕ** — римские цифры, small caps, по центру |
| Подраздел | *A. LISA* — буквы A, B, C…, курсив |
| Подписи рисунков | «Рис. N.», мелкий шрифт |
| Подписи таблиц | «Таблица I.» (римские цифры) |
| Литература | заголовок **ЛИТЕРАТУРА** по центру; `[N]` и текст на одной строке, мелкий шрифт |

## Файлы

| Файл | Назначение |
|------|------------|
| `article.tex` | **Пустой шаблон** — заполняют студенты |
| `example.tex` + `example.pdf` | Пример на базе реальной статьи |
| `misisarticle.cls` | Класс оформления (не менять без нужды) |
| `figures/example/` | Рисунки для `example.tex` |
| `references.bib` | Пример библиографии (опционально) |
| `Makefile` | `make article` / `make example` |

## Как это работает

1. В начале файла: `\documentclass{misisarticle}` — подключается класс (файл `misisarticle.cls` должен лежать рядом с `.tex`).
2. До `\begin{document}` заполняете блоки титула (коды, название, авторы, аннотация).
3. Внутри документа — `\maketitle`, затем `\section{}`, рисунки, таблицы, литература.
4. Компилятор: **XeLaTeX** или **tectonic** (нужны русский язык и Times New Roman).

Команды `\abstract{}` и `\setabstract{}` (а также `\keywords{}` / `\setkeywords{}`) — **эквивалентны**.

### Минимальный пример

```latex
\documentclass{misisarticle}

\grnti{47.01.07, 47.01.09}
\asjc{1707, 2207}
\oecd{1020, 1070}

\title{Название статьи}

\misisauthor{И.~О.~Иванов}{кафедра ... НИТУ «МИСиС»}{Москва, Россия}{student@edu.misis.ru}
\misisauthor{П.~П.~Петров}{кафедра ... НИТУ «МИСиС»}{Москва, Россия}{student2@edu.misis.ru}

\setabstract{Текст аннотации...}
\setkeywords{ключевое слово 1, ключевое слово 2}

\begin{document}
\maketitle

\section{Введение}
Текст раздела...
\end{document}
```

## Быстрый старт (студентам)

### Overleaf

1. New Project → Upload Project → загрузите zip репозитория (или Clone from GitHub).
2. Menu → Compiler → **XeLaTeX**.
3. Откройте `article.tex`, заполните блоки, Recompile.

### Локально

```bash
# macOS: MacTeX; или brew install tectonic
tectonic article.tex
# либо:
make article
xelatex article.tex && xelatex article.tex
```

## Что заполнить в `article.tex`

1. `\grnti{}`, `\asjc{}`, `\oecd{}` — коды (или `{}`, если не нужны).
2. `\title{}` — название.
3. `\misisauthor{ФИО}{кафедра}{город, страна}{email}` — для каждого автора (первый — левая колонка, остальные — правая).
4. `\abstract{}` / `\setabstract{}` и `\keywords{}` / `\setkeywords{}`.
5. Разделы `\section{}`, `\subsection{}`, рисунки, таблицы, `\begin{thebibliography}`.

## Пример (проверка шаблона)

```bash
tectonic example.tex

# → example.pdf
```
