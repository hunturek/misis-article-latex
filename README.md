# Шаблон научной статьи НИТУ «МИСиС» (LaTeX)

Репозиторий: [sadekovlar/misis-article-latex](https://github.com/sadekovlar/misis-article-latex)

Шаблон воспроизводит оформление из эталонной статьи (`Article_1.docx`):

| Элемент | Параметры |
|---------|-----------|
| Формат | A4, **две колонки** (IEEE-style) |
| Поля | верх 1,9 см; низ 2,54 см; лево/право 1,57 см; зазор колонок 0,635 см |
| Шрифт | Times New Roman, **10 pt** (в двухколоночном режиме) |
| Абзацный отступ | 0,51 см |
| Название | 24 pt, на всю ширину страницы |
| Авторы | 11 pt, две колонки (1–2 слева, остальные справа) |
| Аннотация | **Аннотация**— текст (в колонках) |
| Ключевые слова | *Ключевые слова —* текст |
| Раздел | **I. ВВЕДЕНИЕ** — римские цифры, small caps |
| Подраздел | *A. LISA* — буквы A, B, C…, курсив |
| Подписи рисунков | «Рис. N.», мелкий шрифт |
| Подписи таблиц | «Таблица I.» (римские цифры) |
| Литература | мелкий шрифт |

## Файлы

| Файл | Назначение |
|------|------------|
| `article.tex` | **Пустой шаблон** — заполняют студенты |
| `example.tex` + `example.pdf` | Пример на базе реальной статьи |
| `misisarticle.cls` | Класс оформления (не менять без нужды) |
| `figures/from-docx/` | Рисунки для example |
| `references.bib` | Пример библиографии (опционально) |

## Быстрый старт (студентам)

### Overleaf

1. New Project → Upload Project → загрузите zip репозитория (или Clone from GitHub).
2. Menu → Compiler → **XeLaTeX**.
3. Откройте `article.tex`, заполните блоки, Recompile.

### Локально

```bash
# macOS: MacTeX; или brew install tectonic
tectonic article.tex
# либо:
xelatex article.tex && xelatex article.tex
```

## Что заполнить в `article.tex`

1. `\grnti{}`, `\asjc{}`, `\oecd{}` — коды (или оставьте пустыми `{}`).
2. `\title{}` — название.
3. `\misisauthor{ФИО}{кафедра}{город, страна}{email}` — для каждого автора.
4. `\abstract{}` / `\setabstract{}` и `\keywords{}` / `\setkeywords{}`.
5. Разделы `\section{}`, `\subsection{}`, рисунки, таблицы, литература.

## Пример (проверка шаблона)

Скомпилированный эталон:

```bash
tectonic example.tex
# → example.pdf
```

Сравните `example.pdf` с исходным Word-документом: блоки титула, аннотация, разделы, рисунки, таблица, литература.
