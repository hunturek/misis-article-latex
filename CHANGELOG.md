# Changelog

Формат близкий к [Keep a Changelog](https://keepachangelog.com/). Версия класса — в `\ProvidesClass` в `misisarticle.cls`.

## Unreleased

- Пример статьи перенесён в `example/`: в корне остаются класс и пустой шаблон.
- `make dist` собирает zip для Overleaf без примера и рисунков эталона.
- Сборка пишет PDF в `build/` и `example/build/`. Файл `example/reference.pdf` этой командой не перезаписывается.
- Удалён `references.bib`: список литературы набирается вручную в `thebibliography`.
- В тексте шаблона указан кегль 10 pt, как в классе.
- В эталоне учебные адреса вместо личных почт.
- Класс распространяется под LPPL 1.3c.
- GitHub Actions собирает шаблон и пример.

## 1.1 — 2026-08-23

- Оформление статьи сборника НИТУ «МИСиС»: A4, две колонки, титульный блок, подписи рисунков и таблиц, список литературы.
